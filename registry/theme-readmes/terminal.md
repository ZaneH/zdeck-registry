# Wasteland Terminal

Wasteland Terminal is a built-in zDeck appearance. It is included in zDeck; there is no package to download or install.

## What it looks like

Wasteland Terminal is a Fallout-inspired research terminal, not a game-asset copy. It uses olive-black instrument panels, luminous pale green text and a platform monospace stack. Tiles have angular two-pixel frames and static one-pixel scanlines painted into section and tile surfaces only, never over labels.

Horizontal ranges become segmented native meters. Dials, toggles, readings and disabled, unknown and reading-failed states keep their existing meaning. Active toggles gain a restrained phosphor glow, while the saved accent still colours fills, focus and active state. The texture is a repeatable CSS gradient: there is no flicker, sweep, Warp, WebGL, canvas, blur, filter or animation timer. Forced-colors removes the texture and glow.

## Use it

In zDeck, open **Settings → Appearance** and choose **Wasteland Terminal** in the Theme menu. Changes save automatically. To use it for one section only, open that section's menu and choose **Theme → Wasteland Terminal**.

## Preview

The desktop and phone images show the same standard sample deck (`zdeck-sample-deck-1`) with buttons, a slider, a dial, both toggles and a numeric reading. They are local registry images, not a live theme runtime, and they do not prove accessibility, performance or platform support by themselves.
